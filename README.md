# Windows SOC Lab

## About This Project
I am building a home cybersecurity lab to learn how security analysts monitor computers, detect suspicious activity, and investigate potential threats.

## Goals
- Collect Windows security logs.
- Detect suspicious login activity.
- Investigate security alerts.
- Document findings and recommended actions.

## Tools
- Windows
- Wazuh (security monitoring)
- Sysmon (Windows activity monitoring)
- GitHub (project documentation)
